# Responsive Layouts

Treat a layout as an ordered presentation of content, not a desktop canvas that must be compressed. Protect the primary task, readable measure, target sizes, and action order as space changes.

Introduce a breakpoint when the arrangement loses meaning: controls no longer fit, labels become ambiguous, scanning becomes difficult, or dense data needs another representation. Reuse the project’s breakpoint tokens; do not add device-specific values by habit.

For dense views, intentionally choose scrolling, prioritised columns, a summary-detail presentation, or another flow. Do not hide essential information without an alternate path.
