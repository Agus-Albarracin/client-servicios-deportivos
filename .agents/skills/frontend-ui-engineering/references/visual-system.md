# Visual System

Read the product before styling it. Inspect its typography, color roles, spacing scale, radius, elevation, density, iconography, and existing component primitives. Reuse them unless the feature exposes a genuine gap.

Give the primary task the strongest visual weight. Let supporting information, metadata, and secondary actions recede. Use spacing and grouping to explain relationships before adding borders, cards, or decoration.

Use realistic labels, long names, localized text, empty collections, and uncomfortable data values while designing. Avoid visual gestures without a product purpose: gradients, shadows, large corner radii, and decorative cards must reinforce hierarchy or an existing system convention.
