# SEO Checklist

- Inventory each route: index intent, canonical URL, expected status.
- Build and inspect the production output.
- Request each changed route and verify status, canonical, title, description, and robots directives.
- Follow every changed redirect and confirm one hop to the final URL.
- Inspect `robots.txt` and sitemap output for canonical indexable URLs only.
- Validate structured data against visible rendered content.
- Test relevant crawler user agents against the live host when access policy changed.
- Report evidence, blockers, assumptions, and unavailable checks.
